# PHP Usage Resource Compilation

> This is a first draft and should not be considered an exhaustive list.

### Scope

Published research, surveys, and reports of PHP usage in the last 3 years (~August 2023 * August 2026).

### Purpose

Compile a list of research sources to evaluate.

Many of the sources found have different populations and may routinely disagree. The types of sources can be described as Web Crawls, Package Telemetry (Packagist/Composer), Developer Surveys, and Popularity Indices.

## 1. Recurring developer surveys

### 1.1 JetBrains — *The State of PHP* (annual)

The most detailed PHP-specific developer survey. Carved out of the broader *State of the Developer Ecosystem*.

* State of PHP 2025: https://blog.jetbrains.com/phpstorm/2025/10/state-of-php-2025/
* State of PHP 2024: https://blog.jetbrains.com/phpstorm/2025/02/state-of-php-2024/
* Dev Ecosystem 2024 (full): https://www.jetbrains.com/lp/devecosystem-2024/
* Dev Ecosystem 2023 — PHP section: https://www.jetbrains.com/lp/devecosystem-2023/php/
* Laravel Trends 2024 (companion): https://blog.jetbrains.com/phpstorm/2024/09/laravel-trends-2024-the-latest-market-insights/

### 1.2 Zend by Perforce — *PHP Landscape Report* (annual)

Enterprise-leaning survey.

* PHP Landscape Report https://www.zend.com/resources/history-of-php-landscape-report

### 1.3 State of Laravel (annual, community-run)

* Results (all years, filterable by question): https://stateoflaravel.com/results

### 1.4 Stack Overflow Developer Survey (annual)

* 2025 survey: https://survey.stackoverflow.co/2025/
* 2025 technology section: https://survey.stackoverflow.co/2025/technology

## 4. The PHP project

### 4.1 The PHP Foundation — Impact & Transparency Reports (annual)

The primary source on who actually develops PHP and how it is funded. Unusually transparent for an open-source foundation — publishes finances, headcount, and per-repository contribution attribution.

2025 report (pub. 2026-05-27): https://thephp.foundation/blog/2026/05/27/impact-and-transparency-report-2025/
2024 report (pub. 2025-03-31): https://thephp.foundation/blog/2025/03/31/transparency-and-impact-report-2024/
2023 report (pub. 2024-02-26): https://thephp.foundation/blog/2024/02/26/transparency-and-impact-report-2023/
2022 report: https://thephp.foundation/blog/2022/11/22/transparency-and-impact-report-2022/
